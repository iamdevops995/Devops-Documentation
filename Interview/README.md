# Interview Preparation

Questions grouped by area, with the answers written the way you would say them
out loud.

> Sections below match the sidebar. Content is being filled in incrementally.

## AWS

VPC design, IAM roles vs users, EKS networking, cost and reliability trade-offs.

## Kubernetes

Scheduling, probes, rolling updates, service types, RBAC, debugging a failing
deployment.

## Docker

Image layers, multi-stage builds, volumes vs bind mounts, container networking.

## Terraform

State handling, `count` vs `for_each`, module design, drift and imports.

## Linux

Boot process, systemd, permissions, disk and memory diagnostics.

## Scenario Based

"Production is down, walk me through it" style questions, incident handling and
design discussions.
