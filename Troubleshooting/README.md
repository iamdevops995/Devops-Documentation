# Troubleshooting

Symptom-first notes: what you see, what it usually means, what to check next.

> Sections below match the sidebar. Content is being filled in incrementally.

## Kubernetes

Pending pods, CrashLoopBackOff, ImagePullBackOff, OOMKilled, DNS failures,
node not ready.

## Docker

Build cache misses, permission errors on volumes, port conflicts, disk pressure
from dangling images.

## Linux

Full disk and inode exhaustion, service start failures, high load with idle CPU,
DNS and routing problems.

## Pipelines

Credential and permission failures, flaky agents, dependency resolution,
non-deterministic builds.

See also `common_errors` at the repository root.
